# Web arayüzü

Private AI Studio'nun sohbet ekranı. React ile yazıldı, Vite ile çalıştırılıyor.

Arayüz, aynı bilgisayarda 3001 numaralı portta çalışan API'ye bağlanır ve 3000 numaralı portta açılır. Kurulum ve çalıştırma adımları için projenin ana [README](../README.md) dosyasına bakın.

Yalnızca arayüzü başlatmak için bu klasörde şu komutu çalıştırın:

```bash
npm run dev
```
